# Dataset

Program ini menggunakan dataset **Credit Card Fraud Detection** dari Machine Learning Group, Université Libre de Bruxelles (ULB).

**Link dataset:** [Credit Card Fraud Detection – Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

Dataset tidak disimpan di repository ini karena ukurannya (±150 MB) melebihi batas file GitHub (100 MB).

## Cara memakai
1. Buka link di atas, lalu login ke Kaggle.
2. Klik **Download**, kemudian ekstrak file zip-nya.
3. Letakkan `creditcard.csv` satu folder dengan `case_method_fraud_lightgbm.ipynb`.
